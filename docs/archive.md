# 批量解压整理 · zidy

平台：仅 macOS，调用系统自带的 ditto。无需额外解压依赖。

用法：
  zidy [目录]
  zidy --help
  ./hub run zip-tidy [目录]

zidy 直接打开 fzf 预览，默认当前目录；普通 CLI 不提供目录时仍提示输入路径。
命令行中路径包含空格时用引号包裹；TUI 输入框中直接填写路径。

处理规则（保留原工具行为）：
- 扫描输入目录及其直接子目录中的 ZIP，扩展名不区分大小写。
- 不跟随子目录符号链接，不递归解压本轮新解压出的 ZIP。
- 先解压到临时目录，成功后发布为输入目录下与 ZIP 同名的文件夹，再删除原 ZIP。
- 目标存在则跳过；失败保留原 ZIP，并继续处理其他项目。
- 下载包装目录只剩 .torrent、.js、.DS_Store 时删除包装及残留。有其他未处理内容则保留。
- 旧 xxxx.zip 包装目录里的同名解压结果会尝试移到输入目录。
- 清除目录名开头的“[作者] ”及末尾的“ [AI Generated]”；重名时跳过。
- 最后输出统计与一级文件夹名称清单。

这个工具会删除成功解压的原 ZIP、清理已识别的包装残留，并可能重命名已有目录。
TUI 直接输入文字搜索，Ctrl+O 切换目录，Ctrl+R 刷新，Enter 查看规则，Ctrl+X 确认整目录执行，默认取消。
选择单个 ZIP 仅用于预览，执行范围仍为整个目录；零 ZIP 时仍可整理已有目录。
执行界面实时显示日志，完成后 Enter 查看统计。Esc 中断时回收本次解压子进程、清理临时目录，未完成 ZIP 保留；已完成项目不回滚。
普通 CLI 使用 hub run zip-tidy，直接执行上述规则，无需 fzf。

退出码：0 全部成功或无任务；1 存在失败或跳过；2 参数或初始扫描错误；129 终端关闭；130 用户中断；143 收到终止信号。发生错误时输出错误日志路径。

# 端口进程管理 · pinfo

平台：macOS；TUI 依赖 fzf，端口数据来自 lsof，进程身份来自 ps。

用法：
  pinfo [端口]
  pinfo --udp [端口]
  hub tui port-info [端口]
  hub run port-info [--udp] [端口]

默认只查 TCP LISTEN；u 切换 UDP 本地绑定。端口范围 1–65535，按本地端口精确匹配。
不会将连接到目标服务的浏览器 TCP 连接误当作监听进程。同一 PID、协议、本地端口的地址合并显示。

顶部输入端口后按 Enter 精确查询，留空查询全部，不做模糊数字匹配。列表包含对齐的协议、端口、PID、进程、用户、本地地址列。
r 刷新；k 打开终止确认；q/Esc 返回；PgUp/PgDn 翻页预览。
预览显示 PID、进程名、用户、地址、启动时间、工作目录和父进程，不读取进程命令行参数。

确认默认取消。首次发送 SIGTERM，等待最多 3 秒；进程及端口仍存续时，可再次确认 SIGKILL。
每次发送信号前重新核对 PID 启动时间及端口归属；只针对所选 PID，不终止进程组，不自动提权。
权限不足、进程消失或身份变化会显示结果并要求刷新。进程可能由 IDE、服务管理器自动重新启动，需刷新后重新识别。

hub run port-info 仅输出 TSV 表格，不发送信号。看不到的其他用户进程取决于当前系统权限。
CLI 退出码：0 查询成功（含无占用）；2 参数、依赖或读取错误。TUI 无交互终端时返回 2。
